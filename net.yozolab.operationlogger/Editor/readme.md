# Operation Logger

Unity Editor 上の操作を AI(Claude 等)が読みやすい JSONL 形式で記録するエディタ拡張です。
記録したログを AI に読ませることで、「どの作業で詰まっているか」(undo の嵐、値の往復調整、
同じ操作の反復、Play イテレーションの周期、コンパイル待ち、エラーの停滞など)を分析し、
作業を楽にするエディタ拡張の提案につなげることを目的としています。

ロガー自体は分析を行いません。意図が読める粒度・トークン効率のよいログを吐くことに徹しています。

## 使い方

1. メニューの `YozoLab > Operation Logger > Enable Recording` を ON にする(既定は OFF。
   パッケージを入れただけでは何も記録されません)
2. 普段どおり作業する
3. ログは `<プロジェクト>/Logs/YozoLab/oplog/*.jsonl` に書き出される
   (`Open Log Folder` でフォルダを開けます)
4. AI に分析させるときは、同フォルダの `_SCHEMA.md`(スキーマ+分析ガイド)ごと読ませる

### メニュー項目

- **Enable Recording** — 記録の ON/OFF(ユーザー毎の設定)
- **Start New Session** — ログファイルを切り替えて新しいセッションを開始
- **Open Log Folder** — ログフォルダを開く
- **Capture Selection / Window Focus / Assets / Errors** — コレクタ別の ON/OFF(プロジェクト毎)
- **Capture In Play Mode** — プレイ中も編集系イベントを記録するか(既定 OFF。
  play の出入りとエラーは常に記録されます)

## 記録される内容

- プロパティ変更(before/after 値付き。スライダードラッグ等は 1 行に束ねられる)
- 階層構造の変更(生成/破棄/親変更/コンポーネント増減/並べ替え/プレハブ更新)
- Undo/Redo、選択変更、アセット操作(インポート/削除/移動/保存)
- シーン・プレハブステージの開閉、プレイモードの出入り(滞在時間付き)
- ウィンドウフォーカス・アクティブツールの切替、コンパイル/ドメインリロードの所要時間
- Console の Error/Exception(同一メッセージは束ね、レートリミット付き)
- メニュー/ショートカット実行(**Harmony がある環境のみ**、下記参照)

## Harmony について

メニュー/ショートカット実行の捕捉(`cmd` イベント)は Harmony(0Harmony.dll)を使います。
有効化の判定は asmdef の `versionDefines` に任せており、Harmony を同梱する VRCSDK
(`com.vrchat.base`)がプロジェクトに入っていれば自動で有効になります。
このとき定義されるシンボル `YOZOLAB_OPLOG_HARMONY` は**このアセンブリのコンパイル時のみ**
有効で、プロジェクトの Scripting Define Symbols には何も追加されません。
別のパッケージ経由で Harmony を導入している場合は、asmdef の `versionDefines` に
そのパッケージ名のエントリを 1 つ追加してください。
Harmony が無くても他の記録はすべて動作します。

制限: Unity 2022.3 の構造上、**メインメニューバーのマウスクリックは捕捉できません**
(コンテキストメニュー・ショートカット・API 経由は捕捉可能)。メニュー操作の「効果」は
プロパティ/構造/アセットイベントと Undo ラベルに現れます。

## プライバシーと安全性

- 記録は明示的に ON にするまで始まりません(既定 OFF)
- ログはプロジェクトの `Logs/` 配下(Assets 外)のみに書かれ、アセットには影響しません
- ログにはオブジェクト名・アセットパス・エラーメッセージが含まれます。
  共有時は内容を確認してください
