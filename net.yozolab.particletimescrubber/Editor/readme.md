# Particle Time Scrubber

ParticleSystem(子を含むエフェクト全体)の再生位置を、Edit モードのまま時間バーで
自由に行き来しながら確認するエディタ拡張。`YozoLab/Particle Time Scrubber` から開く。

## 使い方

1. シーン上の ParticleSystem を「対象エフェクト」に指定する(子もまとめて扱われる)。
2. 時間バーを動かすと、その時刻のパーティクルの状態が Scene ビューに表示される。
3. Inspector でパラメータを変更すると、再生位置を保ったまま表示が更新される。
4. 再生 / 一時停止 / 先頭に戻る / ループの操作ができる。

## 仕組みと注意

- 対象を確保したとき、全 ParticleSystem の自動シードを切って固定シードを与える。
  これにより同じ時刻を指定すれば毎回同じ絵になる。元のシード設定は、対象を
  外す・ウィンドウを閉じる・Play モードに入る、のいずれかで元へ戻る。
- 時刻の指定は毎回先頭から固定タイムステップで積み直すため、指定時刻が長い・
  パーティクル数が多いほどスクラブは重くなる。
- 再生中は差分シミュレートで進める。一時停止した瞬間に、その時刻をバーで
  指定したときと同じ絵へ揃え直される。
- パーティクルのパラメータ編集は既存の Inspector で行う。このウィンドウは
  時間の操作と結果の反映だけを担当する。
