# Particle Tools

パーティクル制作を支援するエディタ拡張群。

## Particle Scrubber(Scene ビューオーバーレイ)

ParticleSystem(子を含むエフェクト全体)の再生位置を、Edit モードのまま時間バーで
自由に行き来しながら確認する。Unity 標準の Particle Effect パネルの置き換えを
狙っていて、標準パネルの機能(Pause / Restart / Stop / Playback Speed /
Playback Time / Particles 数 / Simulate Layers / Show Bounds / Show Only Selected)を
引き継ぎつつ、時間バーによるスクラブと決定論を足している。

シーン上の ParticleSystem(またはその子)を選択すると現れ、選択を外すと消える。
対象は、選択オブジェクトから一番近い ParticleSystem を見つけ、そこから「親も
ParticleSystem である限り」上へたどった先(=エフェクトのルート)になる。この
束ね方は Unity 標準と同じ。

1. ParticleSystem を選択する。オーバーレイが現れ、既定でループ再生が始まる。
2. 時間バー(全幅・ラベル無し)か「時刻」欄で再生位置を指定すると再生が止まり、
   その時刻の状態が Scene ビューに表示される。
3. Inspector でパラメータを変更すると、再生位置を保ったまま表示が更新される。
4. |◀(先頭 / 再生中は先頭から再生し直し)・▶/❚❚・■(停止)・速度・ループを操作できる。
5. 「境界」「選択のみ」「レイヤー」で標準パネル相当の表示制御ができる。
6. 「即時反映」「標準パネルを隠す」で更新のしかたと標準パネルの表示を切り替えられる。

粒の数の右に `(サブ n)` と出るときは、そのエフェクトに n 個のサブエミッタ
(親のイベントで粒を出してもらう側)がある。

## Particle Color Editor(独立ウィンドウ)

オーバーレイの「色を編集...」か `YozoLab/Particle Color Editor` で開く。
選択中のエフェクトに紐付く色設定を一覧し、その場で編集できる:

- 各 ParticleSystem の Start Color / Color over Lifetime(モードはそのまま、値だけ編集)
- レンダラーが使うマテリアルの Color 型プロパティ(HDR 対応)

変更は Undo 対応で、再生位置を保ったまま即座に反映される。

## 仕組みと注意

- 再生・時刻指定・積み直しは、Unity 標準の Particle Effect パネルが使っている
  内部 API(`ParticleSystemEditorUtils`)へそのまま委ねている。つまり標準パネルの
  Playback Time を動かしたときと同じ道筋で、**サブエミッタも同じように出る**。
  `ParticleSystem.Simulate` を C# から呼ぶ方式は使わない(理由は下記)。
- 対象を確保したとき、全 ParticleSystem の自動シードを切って固定シードを与える。
  これにより同じ時刻を指定すれば毎回同じ絵になる。元のシード設定は、選択を
  外す・Play モードに入る、のいずれかで元へ戻る。
- 時刻の指定は先頭から積み直すため、指定時刻が長い・パーティクル数が多いほど
  スクラブは重くなる。再生中は積み直さず、ネイティブ側が時間を進める。
- 「即時反映」は標準パネルの Resimulate に相当する。ただし標準は変更のあった
  GUI イベントごとに積み直すため、スライダを掴んでいる間ずっと 0 秒目からの
  全ステップが走り、サブエミッタを含むエフェクトではシーンが目に見えて詰まる。
  ここでは標準側の自動積み直しを切ったうえで、変更が収まってから 1 回にまとめて
  掛け直す(最短 0.06 秒待ち・最長 0.25 秒間隔)。重いエフェクトを触っている間は
  「即時反映」を切ればさらに軽くなる。
- 「標準パネルを隠す」は Harmony(0Harmony.dll)がある環境でだけ使える。標準
  パネルは描画のたびにサブエミッタの粒まで数えるので、隠すとその分も省ける。
  Harmony が無ければボタンは無効表示になるだけで、他の機能には影響しない。
- 内部 API を掴めなかった場合や、標準のプレビューが対象を掴んでいない場合
  (選択が ParticleSystem そのものではなくエフェクト内の別オブジェクトのとき等)は、
  `ParticleSystem.Simulate` による簡易シミュレートへ自動で落ちる。そのときは
  オーバーレイに警告が出る。原因が「掴めなかった」なら掴めなかった名前まで、
  「掴めたが時刻が進まない」なら選択の直し方と「再試行」ボタンが出る。
  この経路ではサブエミッタの受け側に直接 Simulate をかけないよう除外している
  (直接叩くと、親のイベントで出た粒が消える・二重に歳を取る・受け側の Emission が
  余計に走る)が、標準の見え方と差は出る。
- マテリアルの色編集はアセット本体を書き換える。同じマテリアルを使う他の
  オブジェクトにも影響する点に注意。
