# Particle Tools

パーティクル制作を支援するエディタ拡張群。

## Particle Scrubber(Scene ビューオーバーレイ)

ParticleSystem(子を含むエフェクト全体)の再生位置を、Edit モードのまま時間バーで
自由に行き来しながら確認する。Unity 標準の Particle Effect パネルの置き換えを
狙っていて、標準パネルの機能(Pause / Restart / Stop / Playback Speed /
Playback Time / Particles 数 / Simulate Layers / Show Bounds / Show Only Selected)を
引き継ぎつつ、時間バーによるスクラブと決定論を足している。

シーン上の ParticleSystem(またはその子)を選択すると現れ、選択を外すと消える。
対象は選択オブジェクトの祖先をたどった最上位の ParticleSystem(=エフェクトの
ルート)になる。

1. ParticleSystem を選択する。オーバーレイが現れ、既定でループ再生が始まる。
2. 時間バー(全幅・ラベル無し)か「時刻」欄で再生位置を指定すると再生が止まり、
   その時刻の状態が Scene ビューに表示される。
3. Inspector でパラメータを変更すると、再生位置を保ったまま表示が更新される。
4. |◀(先頭 / 再生中は先頭から再生し直し)・▶/❚❚・■(停止)・速度・ループを操作できる。
5. 「境界」「選択のみ」「レイヤー」で標準パネル相当の表示制御ができる。

## Particle Color Editor(独立ウィンドウ)

オーバーレイの「色を編集...」か `YozoLab/Particle Color Editor` で開く。
選択中のエフェクトに紐付く色設定を一覧し、その場で編集できる:

- 各 ParticleSystem の Start Color / Color over Lifetime(モードはそのまま、値だけ編集)
- レンダラーが使うマテリアルの Color 型プロパティ(HDR 対応)

変更は Undo 対応で、再生位置を保ったまま即座に反映される。

## 仕組みと注意

- 対象を確保したとき、全 ParticleSystem の自動シードを切って固定シードを与える。
  これにより同じ時刻を指定すれば毎回同じ絵になる。元のシード設定は、選択を
  外す・Play モードに入る、のいずれかで元へ戻る。
- Unity 標準のプレビュー再生とシミュレートの取り合いにならないよう、対象を
  選択している間は標準側の再生を内部 API 越しに止めている。Simulate Layers と
  Show Only Selected も同じ内部 API への橋渡しで、Unity 側の改名などで掴めない
  場合はその項目だけ表示されなくなる。
- 時刻の指定は毎回先頭から固定タイムステップで積み直すため、指定時刻が長い・
  パーティクル数が多いほどスクラブは重くなる。
- 再生中は差分シミュレートで進める。一時停止した瞬間に、その時刻をバーで
  指定したときと同じ絵へ揃え直される。
- マテリアルの色編集はアセット本体を書き換える。同じマテリアルを使う他の
  オブジェクトにも影響する点に注意。
